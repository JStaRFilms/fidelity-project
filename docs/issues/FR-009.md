# FR-009 — UX/accessibility polish and mobile app-like refinement

**Labels:** `Future`, `ux`, `accessibility`, `mobile`

## User Story
As a mobile user, I want the installed PWA to feel responsive, accessible, and polished, so that it is comfortable to use on a phone.

## Proposed Solution
After installability works, perform a mobile UX and accessibility pass across core screens.

## Implementation Flow
1. Test on phone-sized viewports.
2. Fix tap targets, spacing, overflow, and keyboard behavior.
3. Add accessible labels and focus states.
4. Tune PWA theme colors and splash behavior.

## Technical Approach
- Use Lighthouse and manual mobile testing.
- Split large client components and reduce JS where possible.

## Key Considerations
- Polish should follow, not precede, architectural deployability.

## Acceptance Criteria
- [ ] Core pages pass basic accessibility checks.
- [ ] Mobile navigation is usable.
- [ ] Installed PWA has app-like theme and viewport behavior.
- [ ] No critical layout overflow on common phone sizes.
