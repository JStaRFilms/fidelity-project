# FR-005 — PWA installability for Chrome mobile

**Labels:** `MUS`, `pwa`, `mobile`, `vercel`

## User Story
As Anna, I want to open the app in Chrome on my phone and install it from the browser, so that it behaves like a lightweight app.

## Proposed Solution
Add PWA metadata, manifest, icons, theme colors, and an appropriate service worker strategy to the Next.js app.

## Implementation Flow
1. Create `manifest.webmanifest` or Next.js metadata manifest.
2. Add required icon sizes in `public/`.
3. Add mobile metadata in `app/layout.tsx`.
4. Add service worker/caching only after build stability is achieved.
5. Verify install prompt in Chrome/Lighthouse.

## Technical Approach
- Minimum: manifest with `name`, `short_name`, `start_url`, `display`, `theme_color`, `background_color`, and icons.
- Consider `next-pwa` or a hand-rolled service worker depending on Next 16 compatibility.

## Key Considerations
- PWA installability requires HTTPS; Vercel provides this.
- Avoid aggressive caching of API/auth responses.

## Acceptance Criteria
- [ ] App has a valid web app manifest.
- [ ] App has installable icons.
- [ ] Mobile Chrome can install the deployed app.
- [ ] PWA audit passes core installability checks.
