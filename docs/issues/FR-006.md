# FR-006 — Verification and deployment checks

**Labels:** `MUS`, `quality`, `ci`, `verification`

## User Story
As a maintainer, I want repeatable local checks for type-check, lint, build, and PWA assets, so that deployments are predictable.

## Proposed Solution
Use `scripts/vibe-verify.py` as the handoff gate and extend it if needed for nested `nextjs-app/` execution and PWA checks.

## Implementation Flow
1. Confirm verification commands from canonical app root.
2. Run TypeScript, lint, and build checks.
3. Add PWA asset/manifest checks if needed.
4. Document failures and fixes before deployment.

## Technical Approach
- From `nextjs-app/`: `npx tsc --noEmit`, `npm run lint`, `npm run build`.
- From repo root: script may need to `chdir` into `nextjs-app` if root remains non-Node.

## Key Considerations
- The current root `package.json` is empty, so verification should target `nextjs-app`.
- Do not claim done while build is failing.

## Acceptance Criteria
- [ ] Verification script exists.
- [ ] Verification target/root is documented.
- [ ] Type-check, lint, and build comma
